## Featured work

### [Agent Workspace](https://github.com/Posiislight/agent-workspace)

A self-hosted AI coding workflow that connects implementation, automated tests, code review, human approval and GitHub pull requests.

- Isolated virtual machines for task execution.
- PostgreSQL checkpoints to preserve progress across pauses and restarts.
- Bounded retries that escalate unresolved failures for human review.
- Live progress in a React interface through Redis Streams and server-sent events.

**Python · FastAPI · LangGraph · PostgreSQL · Redis · React**
